## 2024-03-24 - Safely merge ARIA attributes for form controls
**Learning:** When form components spread `...props` onto native elements (like `<input>`, `<select>`, `<textarea>`), any internal ARIA attributes (e.g., `aria-describedby` for inline error linking, `aria-invalid`) can be inadvertently overwritten by `props`. Additionally, form controls need robust linking of errors/descriptions using `aria-describedby` for screen reader accessibility.
**Action:** Always explicitly link inline error or description elements to the form control using matching `id` and `aria-describedby` attributes. When passing `...props`, destructure ARIA attributes from props (like `aria-describedby`, `aria-invalid`) and safely merge them with the internal values (e.g., `[props['aria-describedby'], internalDescribedBy].filter(Boolean).join(' ')`), applying them *after* `{...props}` to guarantee they take precedence and combine correctly.
