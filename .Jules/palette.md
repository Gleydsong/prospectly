## 2024-05-24 - Form Control Accessibility Pattern\n**Learning:** Form controls like Textarea and Select were missing `aria-describedby` linking to their respective error messages, unlike the Input component. This makes it difficult for screen readers to associate the error message with the specific form control.\n**Action:** Always ensure inline error messages are explicitly linked to the control using the `aria-describedby` attribute, pointing to a matching `id` on the error text element.
