# Domain docs

O repositório usa layout multi-contexto.

Antes de trabalhar, leia `CONTEXT-MAP.md`, os `CONTEXT.md` relevantes e os ADRs
globais ou específicos do módulo.

Use o vocabulário definido nesses documentos e sinalize qualquer proposta que
contradiga um ADR existente.

Os documentos de domínio serão criados gradualmente por `domain-modeling`
quando conceitos ou decisões forem efetivamente resolvidos.
