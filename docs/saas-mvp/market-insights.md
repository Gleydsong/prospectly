# Market insights — Prospectly SaaS MVP

Síntese para backlog pós-MVP (não implementar nesta branch).

## O que agências/freelancers valorizam

1. **Filtro “sem website”** como feature #1 (padrão de mercado: Get Map Leads).
2. **Qualidade > volume** — categoria + cidade + rating / sinais de intenção.
3. **Pipeline/CRM embutido** — não só export CSV.
4. **Trial sem cartão / créditos iniciais** (ex.: Acha Leads).
5. **Enriquecimento** — WhatsApp/CNPJ (BR); e-mail verificado (global).
6. **Compliance explícito** — Places API oficial vs scraper; transparência LGPD.
