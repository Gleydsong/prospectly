## Interpretação

Antes desta mudança, dashboard (+ Recharts ~111 kB gzip) ia no critical path junto com o bundle de entrada. Depois das lazy routes, o JS do first paint é o entry (~171 kB gzip); código pesado do dashboard carrega só ao navegar para `/`. Settings, imports e billing seguem o mesmo padrão.

Landing: Three.js não é mais obrigatório para o first paint da conversion band — `/globe/earth-reference.png` estático é exibido até visibility + idle (ou permanentemente com reduced-motion / sem WebGL).
