O que foi feito

  • Writer único: moveLeadToStage → outbox v2. lead.created continua v1.
  • Relatórios: dual-read. v2 ignora flags actuais. v1 segue o agora.
  • Copy da página: reclassificar só mexe eventos antigos (v1). Sem cubo, sem migração destrutiva. Sem Webhook de saída no main.
