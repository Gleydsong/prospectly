Spec #179 — Domínio próprio da API

CNAME api.prospectlyonboard.com, TLS, CORS, cookie Lax e redirect OAuth. Código no cliente só depois do health no host novo.

Issue #179 Branch feat/api-custom-domain Wizard HITL

O que esta entrega faz

Ticket 1 é humano: DNS/TLS/OAuth/env. Esta PR traz o wizard, o runbook e um probe Playwright que faz skip se o CNAME ainda não existir. Não aponta o app de produção para o host novo — dig em 2026-09-10 não resolvia api.prospectlyonboard.com.

  • Wizard: ./scripts/api-custom-domain-wizard.sh — sem secrets no git nem na issue.
  • Cookie: none enquanto o app fala com *.onrender.com. lax só com app+api no mesmo site pai, no mesmo deploy (SEC-001).
  • CORS: lista explícita. Sem *. Parser aceita a origem do app.
  • GOOGLE_CLIENT_ID com newline → invalid_client. Boot faz trim.

Vocabulário: Conexão Google (redirect URI) ≠ Sign-In GIS. Worker interno. Produção Asaas fora.
