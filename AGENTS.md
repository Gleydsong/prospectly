## Agent skills

### Issue tracker

As issues e especificações são gerenciadas no GitHub Issues de `Gleydsong/prospectly`. Consulte `docs/agents/issue-tracker.md`.

### Triage labels

A triagem usa os rótulos canônicos `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` e `wontfix`. Consulte `docs/agents/triage-labels.md`.

### Domain docs

O Prospectly utiliza documentação de domínio multi-contexto, com um `CONTEXT-MAP.md` na raiz apontando para os contextos aplicáveis. Consulte `docs/agents/domain.md`.
